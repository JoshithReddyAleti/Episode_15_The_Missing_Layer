# 📖 Reasoning & Test-Time Compute Glossary

**Answer tokens** — the visible output the user sees; distinct from hidden reasoning tokens.

**Best-of-N** — test-time compute pattern: generate N candidates, select best via verifier.

**Beam search** — search over generation states, keeping top-K per level; used in tree search variants.

**Budget tokens** — Anthropic's explicit cap on thinking tokens per response.

**Cascade router** — routing pattern that tries cheap model first, escalates only if confidence is low.

**Chain of thought (CoT)** — prompted reasoning technique from Wei 2022; the pre-reasoning-model paradigm.

**Compute ladder** — the eight-rung framework for climbing test-time compute investment.

**Correlated errors** — verifier and generator make the same mistake; a failure mode of same-model LLM-judge.

**DeepSeek-R1** — open-weights reasoning model from DeepSeek, notable for exposing reasoning traces and cheap pricing.

**Effort dial** — the general term for adjustable reasoning parameters (reasoning_effort, budget_tokens, thinking_budget).

**Extended thinking** — Anthropic's name for Claude's reasoning mode with configurable thinking budget.

**Formal verifier** — deterministic, provably correct check (unit tests, symbolic checker, schema validation).

**Hidden reasoning** — reasoning tokens not exposed to the user (o1, o3 default).

**Iterative refinement** — test-time compute pattern: generate, critique, refine, repeat until verifier passes or budget exhausted.

**LLM-judge** — verifier pattern using an LLM to score candidates against structured or subjective criteria.

**Majority vote** — self-consistency aggregation: run N reasoning chains, take most common final answer.

**Mini reasoning** — smaller reasoning-model tier (o1-mini, o3-mini, Gemini Flash Thinking); cheaper and faster.

**o1 / o3 / o4** — OpenAI reasoning model line; hidden reasoning; configurable via reasoning_effort.

**PRM (Process Reward Model)** — model trained to score intermediate reasoning steps rather than final answers.

**Process supervision** — training approach that rewards correct intermediate reasoning steps (Uesato 2022).

**reasoning_effort** — OpenAI's low/medium/high parameter for reasoning models.

**Reasoning model** — LLM trained via RL on verifiable reasoning tasks; produces internal reasoning traces.

**Reasoning tokens** — internal deliberation tokens generated by reasoning models; billed as output.

**Self-consistency** — Wang 2022 pattern: sample N chains, majority-vote on final answer.

**Self-Refine** — Madaan 2023 pattern: iterative critique-and-refine loop.

**STaR** — Self-Taught Reasoner (Zelikman 2022); bootstrapping reasoning ability via rationalization.

**Task-specific validator** — cheap deterministic verifier that catches obvious errors (syntax, schema, format).

**Test-time compute** — compute spent at inference to improve output quality (as opposed to training-time compute).

**thinking_budget** — Google Gemini's parameter for capping reasoning token count.

**Tree of Thoughts (ToT)** — Yao 2023 pattern: structured search over reasoning states with pruning.

**Verifier** — function mapping (query, candidate) to a score; determines quality of test-time compute patterns.

**Verifier drift** — silent degradation of verifier accuracy over time due to model updates or distribution shift.

**Verifier ensemble** — combining multiple verifiers (formal + task-specific + LLM-judge) with weighted aggregation.

**Visible reasoning** — reasoning tokens exposed to the user (DeepSeek-R1, Claude 3.7, Gemini Thinking).
