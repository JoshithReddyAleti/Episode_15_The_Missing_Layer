# 📖 Enterprise Integration & Compliance Glossary

**ABAC** — Attribute-Based Access Control. Authorization decisions evaluate attributes of user, resource, action, and environment.

**ACL** — Access Control List. Explicit list of principals and their permissions on a resource.

**Adequacy decision** — EU determination that a non-EU country provides adequate data protection, enabling transfers without additional safeguards.

**AI Act (EU)** — EU regulation categorizing AI systems by risk (prohibited, high-risk, limited, minimal) with obligations per tier.

**Anomaly detection** — automated monitoring for suspicious activity patterns.

**Audit log** — immutable, forensically-complete record of system actions.

**Authorization** — determining what an authenticated identity is allowed to do.

**BAA** — Business Associate Agreement. HIPAA contract required between covered entities and vendors handling PHI.

**BCR** — Binding Corporate Rules. Internal rules approved by EU authority for intra-group data transfers.

**BFF** — Backend-for-Frontend. Middle layer between clients and backend services.

**Bring Your Own Key (BYOK)** — customer-managed encryption keys instead of vendor-managed.

**CC controls** — Common Criteria controls in SOC 2 (CC1 through CC9 categories).

**CCPA / CPRA** — California Consumer Privacy Act / California Privacy Rights Act.

**Chain of custody** — documented trail of who accessed evidence during investigation.

**CMK** — Customer-Managed Key.

**Content archive** — plaintext prompts and responses stored separately from audit metadata.

**Covered entity** — HIPAA term for healthcare providers, plans, and clearinghouses subject to HIPAA.

**DLP** — Data Loss Prevention. Software that scans and prevents unauthorized data movement.

**DPA** — Data Processing Agreement. GDPR contract between controller and processor.

**DPF** — Data Privacy Framework. US-EU data transfer framework (successor to Privacy Shield).

**DSAR** — Data Subject Access Request. GDPR user request for their personal data.

**EU AI Act** — see AI Act.

**FedRAMP** — Federal Risk and Authorization Management Program. US government cloud authorization.

**Federation** — trusting external identity provider for authentication.

**GDPR** — General Data Protection Regulation (EU).

**GLBA** — Gramm-Leach-Bliley Act. US financial services privacy law.

**HIPAA** — Health Insurance Portability and Accountability Act (US healthcare).

**HITRUST CSF** — Common Security Framework combining multiple healthcare/security standards.

**HSM** — Hardware Security Module. Physical device for cryptographic key management.

**IdP** — Identity Provider.

**Immutable storage** — write-once storage that cannot be modified after write.

**Ingestion filtering** — restricting which content enters the RAG index based on authorization.

**JWKS** — JSON Web Key Set. OIDC standard for publishing public keys for token verification.

**Least privilege** — granting only the minimum access necessary.

**Legal hold** — retention override for litigation or investigation.

**MFA** — Multi-Factor Authentication.

**mTLS** — mutual TLS. Both client and server authenticate via certificates.

**OIDC** — OpenID Connect. Modern federated identity protocol built on OAuth 2.0.

**PCI-DSS** — Payment Card Industry Data Security Standard.

**Permission-aware retrieval** — vector search that filters by user authorization at query time.

**PHI** — Protected Health Information (HIPAA).

**PII** — Personally Identifiable Information.

**Pre-filter (retrieval)** — applying access filters during the vector search itself, not after.

**Privilege (attorney-client)** — legal doctrine protecting attorney-client communications.

**RBAC** — Role-Based Access Control.

**Right to erasure** — GDPR Article 17 right to have personal data deleted.

**RLS** — Row-Level Security. Database feature restricting row access by identity.

**SAML 2.0** — Security Assertion Markup Language. XML-based federation protocol.

**SCC** — Standard Contractual Clauses. EU-approved contracts for cross-border data transfers.

**Schrems II** — 2020 CJEU ruling invalidating Privacy Shield, complicating US-EU transfers.

**SCIM** — System for Cross-domain Identity Management. Standard for user provisioning.

**SIEM** — Security Information and Event Management. Platform for security event correlation.

**SOC** — Security Operations Center OR Service Organization Controls (SOC 2, SOC 3).

**Sovereign cloud** — cloud offering designed to isolate from parent-company foreign jurisdiction.

**SOX** — Sarbanes-Oxley Act. US financial reporting controls law.

**SSO** — Single Sign-On.

**STS** — Security Token Service. Issues short-lived credentials.

**Tamper-evident** — storage where unauthorized modifications are cryptographically detectable.

**Tenant** — one customer / organization / isolation boundary in multi-tenant SaaS.

**TIA** — Transfer Impact Assessment. GDPR requirement when using SCCs.

**Trust Services Criteria (TSC)** — SOC 2 criteria categories (Security, Availability, Confidentiality, Processing Integrity, Privacy).

**WORM** — Write-Once, Read-Many. Immutable storage class.

**Zero-trust** — security posture treating every request as untrusted, requiring re-verification.
